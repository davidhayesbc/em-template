# Leadership OS (VS Code + Foam)

This repository is a personal knowledge base designed for engineering leadership.
It uses Markdown, Foam, and VS Code to create a lightweight, AI-friendly system
for tracking people, systems, decisions, risks, and strategy.

## Structure

- Daily-Logs: Capture everything you learn each day
- Weekly-Summaries: Synthesize themes and insights
- People: Notes on team members and stakeholders
- Systems: Platform and service documentation
- Decisions: Lightweight ADR-style decision records
- Risks: Operational, architectural, or organizational risks
- Processes: How things work
- Team-Health: Morale, friction, strengths
- 1-1s: Rolling notes per person
- Strategy: Drafts, thinking, alignment docs
- Roadmaps: 6–12 month plans

## Templates

Templates live in .foam/templates/ and can be used via Foam's template system.

## Recommended Workflow

- Daily: Write a log in Daily-Logs
- Weekly: Convert logs into atomic notes and write a summary
- Monthly: Review decisions, risks, and update the Leadership Dashboard
